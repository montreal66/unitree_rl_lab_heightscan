# Bundled Unitree G1 model assets

This directory contains the minimal G1 29-DoF USD dependency required by the
`Unitree-G1-29dof-Mimic-HOI_terrain` tasks. The files are unmodified assets
from Unitree Robotics' `unitree_model` dataset:

https://huggingface.co/datasets/unitreerobotics/unitree_model

Only the G1 29-DoF USD composition and its required configuration layers are
included. No checkpoints, generated logs, or unrelated robot models are
bundled here. Consult the upstream asset source for applicable terms.
